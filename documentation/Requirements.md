# =================JOby application==================

# Descrição Breve:
    O Joby application é uma aplicação web voltada para o gerenciamento de tarefas, tanto individual quanto em grupo.
    Ele visa resolver questões de organização na distribuição de tarefas de atividades privadas ou conjuntas.


# Requisitos:

# 1. Funcionais:

    RF001. Deve ser possível o cadastro (crud) de usuário       (alta importância);
    RF002. Deve ser possível o gerenciamento de tarefas         (alta importância);
    RF003. Deve ser possível o gerenciamento de notas           (alta importância);
    RF004. Deve ser possível gerir o espaço em nuvem            (alta importância);
    RF005. Criação de posts de aviso                            (alta importância);
    RF006. Deve permitir a criação de organizações              (alta importância);
    RF007. Gerar relatórios de tarefas e anotações              (média importância);
    RF008. Deve notificar sobre tarefas, notas e eventos        (média importancia);
    RF009. Deve linkar notas e tarefas                          (média importância);
    RF010. Deve permitir a comunicação entre usuários           (média importância);
    RF011. Inativação da conta e liberação de espaço            (média importência);
    RF012. Reativação da conta;

# 2. Não funcionais:

    RNF001. Deve ser responsivo a computador, notebook, smartphone e tablets;
    RNF002. Deve seguir as normas LGPD;
    RNF003. Deve ser seguro para os usuários;
    RNF004. Deve suportar pelo menos 100 acessos simultâneos;

# 3. Regras de negócio:

    RN001. As ações de um usuário dentro de uma organização é indiferente ao mesmo dentro de uma organização;
    RN002. Um usuário só pode acessar dados e acoes relacionados a ele mesmo;

# Entidades:

    1. Usuario;
    2. Organizações;
